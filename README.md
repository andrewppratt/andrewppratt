## 🚀 Selected Projects

### 🧬 Genomic ML Pipeline

End-to-end machine-learning pipeline for genomic data.

The project explores the intersection of statistical genetics and predictive ML, including:

* GWAS association testing
* Feature selection
* Lasso regression
* Random Forest modeling
* Model evaluation
* Statistical significance testing
* Visualization and pipeline validation

The emphasis isn't only on fitting models—it's on understanding when results are statistically meaningful and debugging the pipeline when assumptions or implementation details fail.

### 👁️ Computer Vision / Image Stitching

Computer-vision project exploring automated image alignment and stitching.

Work includes image processing, feature matching, geometric transformations, and reasoning about how measurements from visual data translate into reliable outputs.

### 🤖 Local LLM Applications

Building applications around locally hosted language models using **Ollama**.

Projects combine:

* Local LLM inference
* FastAPI services
* REST APIs
* PHP / WordPress integration
* SwiftUI clients
* Authentication and networking
* Production-style debugging across multiple layers

The goal is turning model capabilities into usable software rather than treating the model as an isolated experiment.

### 📈 Financial ML System

Machine-learning pipeline for experimenting with financial time-series signals.

Includes:

* Data ingestion and transformation
* Feature engineering
* RSI and MACD
* Rolling statistics
* Classification models
* Probability thresholds
* Backtesting
* FastAPI integration
* React dashboard development
